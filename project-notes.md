Project Notes



Название проекта



Task Service



Назначение



Сервис предназначен для удобного управления личными задачами пользователя.



Функциональные требования



1\. Пользователь может создавать задачи.

2\. Пользователь может просматривать список задач.

3\. Пользователь может редактировать задачи.

4\. Пользователь может удалять задачи.

5\. Пользователь может отмечать задачи как выполненные.



Структура задачи



Каждая задача содержит:



\- ID — уникальный идентификатор

\- Title — название задачи

\- Description — описание задачи

\- Status — статус выполнения

\- Created At — дата создания



Возможные статусы



\- todo — задача создана

\- in\_progress — задача выполняется

\- done — задача завершена



Дальнейшее развитие



В будущем планируется создание REST API, подключение базы данных и запуск приложения в Docker.



Управление задачами



Для каждой задачи предусмотрены следующие действия:



1\. Создание задачи с названием и описанием.

2\. Просмотр подробной информации о задаче.

3\. Редактирование названия и описания.

4\. Перевод задачи в другой статус.

5\. Удаление задачи из системы.



Правила работы



\- Название задачи не может быть пустым.

\- Новая задача получает статус `todo`.

\- Каждая задача имеет уникальный ID.

\- Выполненную задачу можно вернуть в работу.
