Git Merge Conflict



Описание конфликта



Во время выполнения контрольной работы был специально создан конфликт слияния между ветками `main` и `feature/description`.



Причина конфликта



В обеих ветках была изменена одна и та же строка описания проекта в файле `README.md`.



В ветке `main`:



> Task Service — система организации личных и учебных задач.



В ветке `feature/description`:



> Task Service — удобный сервис для планирования и отслеживания задач.



Обнаружение конфликта



При выполнении команды:



`git merge --no-ff feature/description`



Git обнаружил несовместимые изменения и остановил автоматическое слияние.



Команда `git status` показала:



`both modified: README.md`



Разрешение конфликта



Файл `README.md` был открыт вручную. Маркеры конфликта были удалены, а две версии описания объединены в одну:



> Task Service — сервис для планирования, организации и отслеживания личных и учебных задач.



После исправления были выполнены команды:



```bash

git add README.md

git commit -m "merge: resolve README description conflict"

```



Результат



Конфликт был успешно разрешён, слияние завершено. Команда `git status` подтвердила отсутствие незавершённых изменений.
