Task Service



Описание проекта



Task Service — удобный сервис для планирования и отслеживания задач.



Проект предназначен для создания, просмотра, редактирования и удаления задач.



Основные возможности



\- Создание новых задач

\- Просмотр списка задач

\- Редактирование существующих задач

\- Удаление задач

\- Изменение статуса выполнения задачи



Цель проекта



Изучение Git workflow, работы с ветками, коммитами и слияниями.
