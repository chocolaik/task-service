API Plan



Описание



План REST API для сервиса управления задачами Task Service.



Основные endpoints



GET /tasks

Получение списка всех задач.



GET /tasks/{id}

Получение задачи по её идентификатору.



POST /tasks

Создание новой задачи.



PUT /tasks/{id}

Обновление существующей задачи.



DELETE /tasks/{id}

Удаление задачи.



Пример задачи



```json

{

&#x20; "id": 1,

&#x20; "title": "Изучить Git",

&#x20; "description": "Научиться работать с ветками",

&#x20; "status": "in\_progress"

}

```



Планируемые HTTP-коды



\- 200 — успешный запрос

\- 201 — задача создана

\- 400 — некорректный запрос

\- 404 — задача не найдена

\- 500 — внутренняя ошибка сервера



Дальнейшие планы



Реализовать API, подключить базу данных и настроить запуск через Docker.

Дополнительные возможности API

PATCH /tasks/{id}/status

Изменение статуса задачи.

Пример запроса:

```json
{
  "status": "done"
}
```

GET /tasks?status=done

Получение списка задач с фильтрацией по статусу.

Правила API

- Все запросы и ответы используют JSON.
- Каждая задача имеет уникальный идентификатор.
- При создании задачи возвращается HTTP 201.
- Если задача не найдена, возвращается HTTP 404.
